# What is free

Everything published from the
[Putnami repository](https://github.com/Putnami/putnami) is free, and stays
free. Putnami Cloud will offer hosted services on top of it, as separate,
optional offers.

## What the repository gives you

- The `putnami` CLI, on macOS, Linux, and Windows.
- The language extensions: Go, TypeScript, and the experimental Python one.
- The Go and TypeScript frameworks: web, API, auth, persistence, events,
  storage, and validation.
- The protocols, with their schemas, fixtures, and conformance tests.
- The project templates and samples.
- The MCP server that exposes a workspace to coding agents.

## What you can do with it alone

With the repository alone, and without a Putnami Cloud account, you can:

1. Create a workspace, then build, test, lint, and serve every project in it.
2. Check only the projects a change affects, with `--impacted`.
3. Package a project as a container image and publish it to your own registry.
4. Deploy that image anywhere you run containers.
5. Let coding agents work on the workspace through the MCP server.

## What Putnami Cloud will add

Putnami Cloud will offer hosted services for a Putnami workspace. The offers are
not published yet. [putnami.com](https://putnami.com) will describe them, and
this page will link to them when they are.

Nothing on this page will move from free to paid: what the repository gives you
today stays in the repository.
