# Putnami recipes

Generated by `putnami context generate` from the framework's `<language>/samples/recipes.json` indexes; do not edit.

Start a plan from the recipe whose intention matches the request, and name that recipe and its primitives in the plan. Use the primitives; do not hand-roll what the anti-patterns describe. Sample paths are relative to the Putnami framework source repository.
